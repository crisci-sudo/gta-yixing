# 义兴都市 · gta-yixing

一个类 GTA 的 3D 第三人称开放城市原型：程序生成的城市、街机化车辆物理、行人与交通流、警星通缉，以及环形的街头任务。

纯前端，无构建步骤，Three.js 以 ES 模块形式直接引用（`vendor/three.module.js`）。

## 运行

ES 模块不允许从 `file://` 加载，所以必须走 HTTP：

```bash
node serve.js          # 默认 http://127.0.0.1:5173/
node serve.js 8080     # 指定端口
```

浏览器打开 <http://127.0.0.1:5173/>，点「进入义兴」。
若直接用 `file://` 打开，页面会给出可读的错误提示而不是黑屏。

## 玩法

- **开车**：五种车型（轿车 / 跑车 / 面包车 / 出租 / 警车）各有独立的推力、极速、抓地力和质量。手刹会砍掉侧向抓地，用于甩尾；撞墙会掉车体耐久，归零即报废。
- **步行**：车辆不能去的地方可以走。行人会避开快速接近的车，被撞会倒地。
- **通缉**：撞人、偷车、撞警车都会积累「热度」，热度换算成 1–5 颗星。警星越高，出动的警车越多、越凶。甩掉视野后热度会慢慢消退；把车停死并被警车夹住会累积逮捕进度，被捕要上交 15% 的现金。
- **任务**：城市里九个任务牌，三种活儿——送货（开车送到标记点）、检查点竞速（限时穿 6 个环）、突围（带着警星活 42 秒）。超时或死亡即失败。

## 代码结构

```
serve.js               零依赖静态服务器
index.html             HUD / 遮罩层 / importmap
src/core/              数学、输入、镜头骨架、粒子
src/world/             城市生成、空间哈希碰撞、天空与光照
src/entities/          车辆模型与物理、行人、交通 AI
src/systems/           玩家状态机、警星通缉、任务
src/ui/hud.js          DOM 仪表盘与小地图
src/main.js            固定步长主循环与各系统编排
```

城市是确定性的：同一份 `city.js` 常量永远生成同一座城，地面纹理（含车道线、斑马线、公园）同时作为小地图图源。

## 说明

模拟只在玩家周边 260 m 内运行（交通、行人、警车都按距离裁剪），超出范围的交通车会停在原地，等到靠近时再继续。
